# LearnSpace

LearnSpace is a simple and beginner friendly learning platform where users can explore practical courses and learn new skills.


## Features

- Responsive navigation
- Featured courses
- Course category filtering
- FAQ accordion
- Contact form
- JavaScript form validation
- Mobile friendly design

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript
